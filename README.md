# Политика конфиденциальности JAM_STUDIO

Дата обновления: 4 октября 2026 года.

Разработчик: Egor Plaxienko.  
Контакт для поддержки и вопросов конфиденциальности: studiojam.sup@gmail.com.

## О плагине

JAM_STUDIO — плагин с инструкциями для подготовки текстовых промптов для фото и видео, работающий внутри ChatGPT или Codex.

Плагин не подключён к внешним API, серверам или базам данных разработчика и не использует собственную аналитику.

## Данные при использовании плагина

Разработчик не получает через JAM_STUDIO сообщения, изображения, файлы и другие персональные данные пользователей и не хранит их на собственных серверах.

Содержимое диалогов обрабатывается средствами платформы OpenAI. Правила обработки, хранения и удаления этих данных определяются условиями соответствующего сервиса и настройками пользователя.

Политика конфиденциальности OpenAI:  
https://openai.com/policies/privacy-policy/

Управлять историей, настройками обработки данных и удалением данных можно средствами соответствующего сервиса OpenAI.

Если пользователь самостоятельно переносит промпты или файлы во внешние инструменты генерации, обработка данных в этих инструментах регулируется их собственными правилами.

## Обращения в поддержку

Если вы отправляете письмо на studiojam.sup@gmail.com, разработчик получает адрес отправителя, содержание письма и приложенные вами файлы. Эти данные используются для ответа и решения обращения.

Почта обслуживается Gmail. Обработка данных почтовым сервисом регулируется политикой Google:  
https://policies.google.com/privacy

Переписка хранится в почтовом ящике до ручного удаления. Вы можете запросить удаление своего обращения и вложений, написав на studiojam.sup@gmail.com. Разработчик удалит их, если сохранение не требуется по закону.

Не отправляйте пароли, платёжные реквизиты и другие сведения, которые не нужны для решения обращения.

## Получатели данных

При обычном использовании JAM_STUDIO разработчик не получает пользовательский контент и не передаёт его другим лицам.

Данные обращений доступны разработчику и обрабатываются почтовым сервисом Google. Разработчик не продаёт их и не использует для рекламы. Передача иным получателям возможна, если этого требует закон.
